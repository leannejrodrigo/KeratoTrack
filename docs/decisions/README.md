# Architecture decision records

An architecture decision record (ADR) is a short, dated note explaining one
significant decision: the context, what was decided, the alternatives, and the
consequences. ADRs are never rewritten to change history. If a decision
changes, a new ADR supersedes the old one, and the old one is marked as
superseded.
