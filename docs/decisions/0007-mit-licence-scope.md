# ADR 0007: MIT licence for original code only

**Date:** 2026-11-07 · **Status:** Accepted

## Decision

Original KeratoTrack code and documentation are released under the MIT
licence. Fonts, third-party libraries, research datasets and material from
published papers keep their own terms. The project licence grants no right to
obtain or redistribute any dataset. Details are in
[licensing.md](../licensing.md).

## Consequences

- Simple, widely understood terms for portfolio reviewers.
- Third-party licence files (for example the fonts' OFL) must be included when
  that material is added.
